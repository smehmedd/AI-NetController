## 🚀 Key Major Architectural Milestones in v3.0.0

### 1. Poppy & Vibrant Cyberpunk Visual Overhaul
- **Deep OLED Void Canvas (`#030712`)**: Replaced flat dark navy with deep OLED cyber black for maximum visual contrast against neon illuminations.
- **4-Beam Radiant Aurora Refraction Field**:
  - **Electric Cyan (`#00F0FF`)**: Dynamic top-right ambient beam with rich multi-stop radial gradient.
  - **Neon Violet (`#8B5CF6`)**: Center-left luminous glow.
  - **Mint Emerald (`#00F59B`)**: Bottom-right network beacon pulse.
  - **Cyber Sunset Amber/Magenta (`#F43F5E` / `#FFB703`)**: Center-right warm sunset accent.
- **Metallic Specular Cyan Headings**: The `Fleet Control` title features an iridescent metallic sheen (`from-white via-cyan-100 to-cyan-400`) with metallic cyan drop-shadow reflections (`drop-shadow-[0_2px_14px_rgba(0,229,255,0.35)]`).
- **Luminous Specular Glassmorphism**: Cards and floating chrome now feature enhanced saturation (`backdrop-saturate-[210%]`) with vivid specular cyan rims (`border-t-cyan-400/40`) and glowing outer ambient halos (`box-shadow: 0 16px 40px rgba(0,0,0,0.6), 0 0 24px rgba(0,229,255,0.08)`).
- **Poppy High-Contrast Action Buttons & Indicators**:
  - **Online Latency Badge**: Pulsing neon emerald beacon with glowing halo (`shadow-[0_0_12px_rgba(16,185,129,0.35)]`).
  - **Sleeping Host Badge**: Warm amber glow (`drop-shadow-[0_0_6px_rgba(245,158,11,0.4)]`).
  - **Wake Button**: Electric amber-to-orange gradient with a 24px neon aura (`shadow-[0_0_24px_rgba(245,158,11,0.45)]`).
  - **Terminal & Screen Buttons**: Vivid sky/cyan badges with specular borders.
  - **CPU & RAM Gauges**: Neon electric cyan (`#00F0FF`) and violet (`#8B5CF6`), shifting to fiery rose/amber on high load (`#FF2A6D`).
- **Floating Pill Nav Lens**: Enhanced active tab capsule with high-transparency specular glass and vivid glowing cyan icon reflections (`drop-shadow-[0_0_12px_rgba(0,229,255,0.9)]`).

### 2. Universal Zero-Overflow Multi-Resolution Safeguards
- **Universal Width & Overflow Constraints**: Global `box-sizing: border-box`, `max-width: 100vw`, and `overflow-x: hidden` enforced on `html`, `body`, `#root`, and main shells. All images, canvas elements, SVGs, and video frames bounded with `max-width: 100%`.
- **Ultra-Narrow Foldables (280px–360px, e.g. Galaxy Z Fold cover)**: Header controls wrap responsively (`flex-wrap gap-1.5`) so buttons never push outside the right viewport edge. `[+ Add Host]` and filter chips collapse text to icon-only buttons on `< 400px` screens. Card hostnames enforce `truncate min-w-0 flex-1` instead of arbitrary line breaks.
- **Short Landscape Viewports (height <= 480px, e.g. 844x390, 896x414)**: Floating pill nav compacts to `46px` height. All dialogs and bottom sheets are clamped to `max-h-[92dvh]` with scrollable interiors (`overflow-y-auto overflow-x-hidden flex-1`), ensuring headers and action buttons are always reachable.
- **Tablets & Ultrawides (21:9 at 3440px & 32:9 at 5120px)**: Grid scales from 1 to 6 columns using `minmax(0, 1fr)` to prevent grid blowout.

### 3. 100% Visual & Interactive Parity with Google AI Studio PWA
- **Self-Hosted Offline Typography Engine**: Extracted and bundled 44 Latin & Cyrillic WOFF2 fonts for `Onest`, `Plus Jakarta Sans`, and `JetBrains Mono` directly inside `apps/web/public/fonts/` with `@font-face` definitions in `fonts.css`. Zero Roboto fallback, zero external CDN latency, 100% offline parity.
- **True Edge-to-Edge System Bars**: Enabled `window.setDecorFitsSystemWindows(false)` with transparent status and navigation bars. Saturated background gradients seamlessly flow under camera notches and home gesture pills.
- **OS Algorithmic Force Darkening Disabled**: Disabled `FORCE_DARK_OFF` and `setAlgorithmicDarkeningAllowed(false)` in Android WebView, preventing Android 10–15 Dark Mode from muddying or washing out custom cyber palettes.
- **CSS Containment Glowing Shadow Fix**: Replaced `contain: layout style paint;` with `contain: layout style;` in `.contain-paint-layout`. Diffuse neon box shadows, halos, and spring bouncy animations render without clipping.
- **Adaptive Cyber Radar Vector Icon**: Upgraded launcher icon (`ic_launcher.xml`) to a high-resolution adaptive cyber radar squircle matching `icon-192.svg`.

### 4. 100% User-Driven Fleet Setup & Zero Initial Placeholders
- **Clean Initial State**: Removed all hardcoded mock/placeholder PCs (`CST-LAB-PC-1`, `HOME-WORKSTATION`, `CST-FIELD-LAPTOP`, `NFS-STORAGE-SERVER`), dummy WoL schedules, and synthetic packet logs.
- **Dedicated Empty-State Experience**: When opening the app fresh, a clean dashboard invites the operator to register computers manually or discover them over the local subnet.
- **Real Kernel ARP Network Discovery**: Subnet scanning reads the operating system's ARP table (`/proc/net/arp` on Android, `arp -a` on Windows/Linux) to report actual active LAN hardware with zero synthetic ghost devices.

### 5. Maximum Smoothness & Total Haptic Removal Overhaul
- **Complete Haptic Elimination**: Completely eliminated all haptic feedback, vibration hardware calls, and `android.permission.VIBRATE` permissions across web frontend, native bridge, and mobile manifests. Zero vibration delays, zero audio context thread overhead, and instantaneous touch responses.
- **Pure Hardware Accelerated WebView**: Configured `View.LAYER_TYPE_HARDWARE`, disabled overscroll jitter (`OVER_SCROLL_NEVER`), and enabled `RenderPriority.HIGH` with `LOAD_DEFAULT` caching for locked 60/120/144 FPS buttery UI.
- **Zero Fake Telemetry Churn**: Removed background simulated jitter pulse loop, guaranteeing zero unnecessary React re-renders when the fleet is idle or awaiting real network updates.

### 6. Native Android Hardware UDP Wake-on-LAN Dispatch
- **Direct Wi-Fi Broadcast**: Broadcaster constructs standard 102/108-byte IEEE 802.3 Magic Packets and delivers them directly through Android's native Wi-Fi hardware via Java `DatagramSocket`.
- **Zero Relay Required**: Operates even when target PCs are completely powered off (ACPI S5 deep sleep) without requiring a middleman relay server.
- **Dual Trigger**: Callable via `window.AndroidBridge.sendWolUdp` and intercepted transparently on `POST /api/wol`.
